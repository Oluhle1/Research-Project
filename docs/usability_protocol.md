# Usability task protocol — not yet conducted

Functional automated testing is separate from participant usability testing.
No participants have been recruited and no user acceptance result is claimed.

For a small convenience sample of 3–5 consenting representative research users,
use only synthetic data. Explain voluntary participation and avoid collecting
names or applicant information. Give each participant an anonymous study label.

Tasks, in order:

1. Download the synthetic template and upload it successfully.
2. Find the reported non-recipient count and its resolved-pass denominator.
3. Locate one unresolved screening reason and explain it.
4. Explain why a probability is neither statutory eligibility nor observed receipt.
5. Download results and identify the rule/model versions in the audit manifest.

Record task completion, seconds taken, error count, a 1–5 ease rating and brief
anonymous observations. Record assistance given. Summarize only actual observed
outcomes, including failures; this sample cannot establish broad acceptance.

Do not describe an automated Streamlit test as a nontechnical participant test.
